# NEXUS PC PRO

Мониторинг и обслуживание ПК в одном лёгком приложении. Написан на Rust, интерфейс — egui/eframe, собирается в один исполняемый файл для Windows, macOS и Linux.

## Возможности

- **Обзор** — ключевые показатели: процессор, память, swap, сеть, диски, температура, сведения об ОС;
- **Мониторинг** — графики нагрузки ЦП, ОЗУ и сети в реальном времени, загрузка по ядрам;
- **Диски** — подключённые накопители и занятое пространство;
- **Процессы** — таблица процессов с поиском и безопасным завершением;
- **Видеокарта** — список графических адаптеров и драйверов;
- **Сканер** — поиск временных файлов, кэша и журналов;
- **Очистка** — удаление найденного с отчётом;
- **Инструменты** — запуск штатных утилит операционной системы;
- **Темы** — Midnight, Carbon, Aurora.

## Скачивание

Готовые сборки публикуются в [Releases](https://github.com/codifystudio/nexus-pc-pro/releases):

| Платформа | Файл |
|---|---|
| Windows x64 | `nexus-pc-pro-*-windows-x86_64.exe` |
| macOS (Apple Silicon) | `nexus-pc-pro-*-macos-aarch64.tar.gz` |
| macOS (Intel) | `nexus-pc-pro-*-macos-x86_64.tar.gz` |
| Linux x64 | `nexus-pc-pro-*-linux-x86_64.tar.gz` |

На macOS после распаковки может понадобиться снять карантин: `xattr -cr nexus-pc-pro` (сборка не подписана сертификатом Apple). В Linux требуются стандартные библиотеки X11/Wayland (на Ubuntu/Debian: `sudo apt install libxkbcommon-x11-0`).

## Сборка из исходников

```bash
cargo build --release
# результат: target/release/nexus-pc-pro(.exe)
```

Требуется Rust 1.75+.

## Тесты

```bash
cargo test
```

Набор `tests/security_tests.rs` закрепляет гарантии безопасности: белый список путей с fail-closed канонизацией, запуск утилит без командной оболочки, двойную проверку (pid, время старта) перед завершением процесса, обязательное подтверждение опасных действий и троттлинг вывода фоновых задач.

## Безопасность

- Сканер и очистка работают **только** с канонизированными корнями из статического белого списка; несуществующий корень — отказ, без откатов на текущий каталог; символические ссылки никогда не обходятся;
- завершение процесса принимается только при совпадении пары (pid, время старта) — защита от переиспользования PID;
- системные утилиты запускаются напрямую по замкнутому перечислению, без shell и без участия пользовательского ввода;
- опасные действия выполняются только после явного подтверждения;
- вывод фоновых задач ограничен по объёму с подсчётом отброшенных байтов;
- настройки жёстко нормализуются при каждой загрузке, запись — атомарная.
